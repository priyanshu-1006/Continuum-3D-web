# Event modal artwork

The original three-world kit is in `public/assets/CONTINUUM_2027_Event_Modal_Kit`. Its manifest and SHA-256 checksums were checked before staging the 19 supplied runtime assets. The runtime sprites keep their alpha channels and are resized for the size used in the dialog. Reference screenshots and source sheets serve as design references.

The new artwork for Neural Nexsus and Battleforge was generated with the built-in ImageGen tool, using the kit’s asset overview and, for the scene art, the corresponding Continuum poster. Runtime files are stored under `public/continuum/events/{neural-nexsus,battleforge}` and the themed beams and dividers are under `public/continuum/events/shared`. Each new world uses an opaque WebP scene and separate transparent pennant, emblem, and beam PNGs. The two added circuit dividers use the supplied circuit geometry and the new accent colors.

The live interface uses real HTML for the event details, tabs, and registration. Known event facts come from `lib/events.ts`. The workshop and esports registration links are pending, and the Prize tab shows the same announcement state where the project has no prize data.

Create a new portrait 4:5 environmental illustration for the LEFT image window of the Neural Nexsus AI/ML workshop game quest. Rich crafted voxel textures, strong architectural perspective, turquoise reflected light on pavers. Dominant deep teal/amethyst, distinct from kit's green Nexathon. Central subject around y=49%, allow enough framing for landscape mobile crop. Full bleed artwork. No UI, no typography, no logo, no numbers, no border, no people, no poster.
